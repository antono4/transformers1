# 🚀 Transformers1: Fullstack Professional Showcase

Welcome to **Transformers1**, a comprehensive showcase of modern software engineering. This repository contains two distinct, high-performance projects designed to demonstrate versatility in both web development and system-level tooling.

---

## 🌐 Project 1: Professional Portfolio (Next.js Edition)
A high-end, production-ready personal portfolio designed for maximum impact and performance.

### ✨ Key Features
- **Modern Tech Stack**: Built with **Next.js**, **Tailwind CSS**, and **Framer Motion**.
- **Dynamic Data Engine**: Projects are managed via a separate `projects.json` file, allowing for seamless content updates without code changes.
- **Cinema-Grade Animations**: Implemented staggered entry animations and layout transitions for a premium user experience.
- **Enterprise SEO**: Fully optimized with OpenGraph and Meta tags for professional sharing on LinkedIn, Twitter, and Facebook.
- **Responsive Design**: A mobile-first approach ensuring a pixel-perfect experience across all device sizes.

### 🛠️ Tech Stack
`Next.js` | `React` | `Tailwind CSS` | `Framer Motion` | `JSON`

---

## 🌤️ Project 2: Enterprise Weather TUI (Python Edition)
An advanced, interactive Text User Interface (TUI) that transforms a simple weather script into a professional dashboard.

### ✨ Key Features
- **Interactive Dashboard**: Built with the **Textual** framework, featuring a real-time updating interface with a sidebar and main content area.
- **Advanced Metrics**: Fetches real-time Temperature, "Feels Like" temp, Humidity, Wind Speed, UV Index, and Precipitation.
- **Global Favorites System**: A persistent storage system using JSON to save and manage favorite cities.
- **7-Day Forecast**: Integrated weekly outlook with Max/Min temperature projections.
- **Professional UX**: Implements a custom color palette, data tables, and a seamless search-and-update loop.

### 🛠️ Tech Stack
`Python 3.x` | `Textual` | `Rich` | `Requests` | `Open-Meteo API` | `JSON` | `CSV`

## 🚀 Getting Started

### 1. Running the Portfolio
```bash
cd portfolio-pro
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Running the Weather TUI
```bash
cd weather_cli
pip install -r requirements.txt
python weather_tui.py
```
